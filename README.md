# public-lands-burden

County-level analysis of how federal land ownership in the western US relates to
local government finances. Combines the 2012 Census of Governments: Finance
(COG-F) individual-unit data with federal land shares (PAD-US / BLM SMA),
ERS Rural-Urban Continuum Codes, and Census TIGER boundaries.

## Layout

| Folder    | Contents |
|-----------|----------|
| `code/`   | R scripts (see pipeline below) |
| `input/`  | External source data. Large raw datasets are not tracked; place them here locally (see below). |
| `output/` | Files generated by the scripts (`.rds`, `.csv`, `.xlsx`) |
| `docs/`   | Reference material, e.g. `Class Types.txt` (COG-F item-code → class-code lookup) |

Paths are resolved with [`here`](https://here.r-lib.org/), so scripts work when
run from anywhere inside the repo.

## Raw data (not in git)

Download these and place them under `input/`:

```
input/
├── 2012 COG-F/
│   ├── 2012FinEstDAT_07242018modp_pu.txt   # COG-F individual unit finance file
│   └── Fin_GID_2012.txt                    # COG-F government ID directory
├── PAD-US/
│   └── PADUS4_1_State<XX>.gdb              # PAD-US 4.1 state geodatabases
└── SMA_WM.gdb                              # BLM Surface Management Agency
```

`ruralurbancodes2013.xls` is tracked, and `Cty_Agg.R` / `plots.R` re-download it
from USDA ERS if it is missing. TIGER boundaries are downloaded by `tigris` at run time.

## Pipeline

Run in this order:

1. **`All_Gov_West.R`**: parses the COG-F finance + GID files for western states
   → `output/cogf_2012w.rds`, `output/2012_All_Gov_West.xlsx`
2. **`fed_share_acs.R`**: computes federal land share per county from PAD-US / SMA
   and joins it to the COG-F data
   → `output/fed_share_west.csv`, `output/cogf_2012w_fed.rds`, `output/cogf_2012w_fed.xlsx`
3. **`unincorp_share.R`**: computes unincorporated area share per county
   (slow spatial step; run once) → `output/unincorp_share.csv`
4. **`Cty_Agg.R`**: aggregates to county level and joins land share, RUCC metro
   status, and unincorporated share → `output/Cty_Agg.rds`, `output/County_Aggregate.xlsx`
5. **`Models.R`**: regression models on `Cty_Agg.rds`
6. **`plots.R`**: correlation bar charts and scatter plots

Other scripts:

- `agg r code (Overton).R`: earlier, simpler county aggregation from `cogf_2012w.rds`
- `parse_Fin_GID_2012.R`: standalone parser that writes the GID file to a formatted
  `.xlsx` (uses a hardcoded local working directory)
