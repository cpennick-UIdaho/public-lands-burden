# public-lands-burden

County-level analysis of how federal land ownership in the western US relates to
local government finances. Combines the 2012, 2017, and 2022 Census of
Governments: Finance (COG-F) individual-unit data with federal land shares (PAD-US / BLM SMA),
ERS Rural-Urban Continuum Codes, and Census TIGER boundaries.

## Layout

| Folder    | Contents |
|-----------|----------|
| `code/`   | R scripts, numbered in run order (see pipeline below); `code/scratch/` holds old/unused scripts |
| `input/`  | External source data. Large raw datasets are not tracked; place them here locally (see below). |
| `output/` | Files generated by the scripts (`.rds`, `.csv`, `.xlsx`); `output/scratch/` holds old outputs |
| `docs/`   | Reference material, e.g. `Class Types.txt` (COG-F item-code → class-code lookup) |

Paths are resolved with [`here`](https://here.r-lib.org/), so scripts work when
run from anywhere inside the repo.

## Raw data (not in git)

Download these and place them under `input/`:

```
input/
├── 2012 COG-F/
│   ├── 2012FinEstDAT_07242018modp_pu.txt   # COG-F individual unit finance file
│   └── Fin_GID_2012.txt                    # COG-F government ID directory
├── 2017 COG-F/                             # 2017_Individual_Unit_File.zip from census.gov
│   ├── 2017FinEstDAT_09202024modp_pu.txt
│   └── Fin_PID_2017.txt
├── 2022 COG-F/                             # 2022_Individual_Unit_File.zip from census.gov
│   ├── 2022FinEstDAT_07152026modp.txt
│   └── Fin_PID_2022.txt
├── PAD-US/
│   └── PADUS4_1_State<XX>.gdb              # PAD-US 4.1 state geodatabases
└── SMA_WM.gdb                              # BLM Surface Management Agency
```

`ruralurbancodes2013.xls` is tracked, and `04_Cty_Agg.R` / `07_plots.R` re-download it
from USDA ERS if it is missing. `06b_Models_Spatial_Commute.R` likewise downloads the
ACS county-to-county commuting flows (2006–2010, 2011–2015, 2016–2020) to
`input/commuting_flows_<vintage>.xlsx`.
TIGER boundaries are downloaded by `tigris` at run time.

## Pipeline

Run in this order:

1. **`01_All_Gov_West.R`**: parses the COG-F finance + directory files for each wave
   (2012 and 2017+ record layouts) for western local governments
   → `output/cogf_west.rds`
2. **`02_fed_share_acs.R`**: computes federal land share per county from PAD-US (one
   vintage, constant across waves) and pulls ACS 5-year income, households, and
   education for each wave (needs `CENSUS_API_KEY`)
   → `output/fed_share_west.csv`, `output/acs_west.csv`
3. **`03_unincorp_share.R`**: computes unincorporated area share per county
   (slow spatial step; run once) → `output/unincorp_share.csv`
4. **`04_Cty_Agg.R`**: aggregates to a county × wave panel and joins land share, ACS,
   RUCC 2013 metro status, and unincorporated share → `output/Cty_Agg.rds`,
   `output/County_Aggregate.xlsx`
5. **`05_Models.R`**: OLS regression models on the 2012 wave of `Cty_Agg.rds`
6. **`06_Models_Spatial.R`**: brms panel models with a BYM2 county spatial effect
   (rook contiguity) on all waves of `Cty_Agg.rds`
   - **`06b_Models_Spatial_Commute.R`**: alternative to step 6 with the same models, but
     the ICAR is weighted by ACS commuting flows between counties (links below 0.5%
     of workers dropped). Each wave uses the latest flows vintage ending before it
     (2006–10 → 2012, 2011–15 → 2017, 2016–20 → 2022), so the spatial component is
     wave-specific. Fit in Stan directly (`code/stan/bym2_weighted.stan`) because brms `car()` only accepts
     binary adjacency
7. **`07_plots.R`**: correlation bar charts and scatter plots (2012 wave)

Scripts are numbered in run order; a letter suffix (`06b_`) marks an alternative
to the step with the same number. Steps 1–3 are independent of each other;
step 4 needs all three.

Old or unused files live in `scratch/` subfolders and are not part of the pipeline:

- `code/scratch/`: `agg r code (Overton).R` (earlier 2012-only aggregation; writes
  `Cty_Agg.rds`, so don't run it) and `parse_Fin_GID_2012.R` (standalone GID parser
  with a hardcoded working directory)
- `output/scratch/`: outputs from the earlier 2012-only pipeline (`cogf_2012w*`,
  `2012_All_Gov_West.xlsx`, `top_nonmetro*.xlsx`, `County_Aggregate.csv`)
